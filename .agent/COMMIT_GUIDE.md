# 커밋 가이드라인

- 학습 진도 단위로 커밋한다. study0부터 study10, studyMidpoint, study11부터 study18, studyFinal 순으로 진행한다.
- 해당 장에 먼저 등장하는 기능은 TSX와 JSX를 같은 커밋에 넣는다.
- 커밋 메시지는 영어 Conventional Commits 타입과 한글 설명을 사용한다. 예를 들어 `feat: study5 글쓰기 폼과 오류 처리 추가`로 쓴다.
- 작업 종료 전 두 버전의 실행, 학습 문서 검증, Git에서 무시한 환경·데이터 파일, Notion 반영 내역을 확인한다.
